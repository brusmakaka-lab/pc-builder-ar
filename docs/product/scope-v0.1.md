# Scope V0.1

La V0.1 prepara una base para este flujo:

1. Crear build.
2. Elegir CPU.
3. Elegir motherboard.
4. Elegir GPU.
5. Elegir RAM.
6. Validar compatibilidad basica.
7. Mostrar precio total.

Incluido ahora:

- Proyecto Next.js con App Router, TypeScript estricto y Tailwind CSS.
- Modulos iniciales para builds, compatibilidad, pricing y db.
- Pantalla minima de build actual.
- Tests unitarios para comportamiento de dominio existente.

Fuera de scope:

- Scraping, tiendas, historial, alertas, autenticacion, pagos, IA, benchmarks, usado, 3D y microservicios.
